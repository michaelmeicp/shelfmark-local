# Shelfmark｜讀看清單

私人書籍、電影與影集收藏誌。把「想看什麼」「看到哪裡」與心得放在同一處。預設繁體中文。沒有帳號、廣告、外部字體或遠端資料 API。介面與幾何封面皆為原創，示範作品與創作者都是虛構的。

## 啟動
需要 Python 3；開發測試需要 Node.js 22。無需安裝套件或建置。
```sh
npm start
# 開啟 http://127.0.0.1:8080
npm test
```
也可以執行 `python3 -m http.server 8080 --bind 127.0.0.1`。請透過 HTTP 而非直接點開 HTML。首次完整載入後，支援服務工作者的瀏覽器可在同一網址離線重開。服務工作者需要 localhost 或 HTTPS。此專案本身不部署公開網站。

## 日常使用
- 初次進入為示範收藏。開啟「資料管理」→「切換到私人收藏」即可從空白開始；切換不會刪除另一空間。
- 在「作品庫」新增作品，或選取卡片編輯、封存、還原、刪除。搜尋名稱、創作者、標籤，疊加媒介、狀態、標籤及最愛／封存條件。格狀與列表皆支援鍵盤操作。
- 書籍記頁數（0 到總頁數）。影集填入各季集數，以及最後看完的季／集：S1E0 表示尚未開始；其餘季從第 1 集開始計算。電影以「已完成」記為看過。書籍與影集的清單狀態由使用者設定，不更改輸入的進度。
- 頂部數字統計未封存作品。「時間線」依每部作品最後編輯時間排序，不是每次操作的完整歷史。卡片與搜尋都不會顯示私人筆記。
- 完整備份包含筆記、標籤、星等、封存作品和進度；務必小心保存。分享清單只輸出未封存作品的名稱、媒介及創作者。兩者均先顯示輸出預覽，下載需要再次操作，不會自動傳給任何人。
- 完整備份可以匯入空白空間還原，或合併到現有收藏。匯入先驗證整份檔案，再顯示新增／重複數，確認後才寫入。ID 相同，或同媒介且名稱經 Unicode NFKC、大小寫、空白正規化後相同，均視為重複；現有作品優先，檔案內以第一筆被接納的作品為準。不覆寫既有進度。分享清單不可當作備份匯入。

## 儲存與限制
資料存在目前瀏覽器、目前網址的 localStorage，未加密。清除瀏覽器資料、使用私密模式或更換瀏覽器／連接埠，都可能使原資料無法取用。重要資料請定期匯出備份。不支援多人或多分頁同步、外部搜尋、雲端備份、自動取得封面或串流。儲存額度依瀏覽器而異；寫入失敗時不替換當前收藏。每個空間上限 5,000 部作品，單一匯入檔上限 16 MiB。

## 結構
- `index.html`、`styles.css`：語意化介面與響應式版面
- `app.js`：檢視、搜尋、儲存、匯入／匯出與空間切換
- `editor.js`：作品編輯與確認流程
- `covers.js`：本機產生的幾何封面
- `model.js`：驗證、進度、統計、篩選、備份與合併規則
- `model.test.js`：Node 原生測試；GitHub Actions 於 push／PR 執行
- `sw.js`：同源離線介面快取；產品更新時應遞增快取版本
